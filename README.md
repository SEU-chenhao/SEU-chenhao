# 党史国情知识竞赛复习题库

[打开公开刷题网页](https://chenhao20215486-web.github.io/SEU-chenhao/)

根据东南大学交通学院先行工作站的「赛题剧透｜党史国情提前学」整理。网页可按年份、期次、专题和题型筛选，提交后查看答案和解析。收藏、错题与练习进度保存在当前浏览器。换浏览器或访问另一个域名时，会使用该入口自己的记录。

## 更新题库

1. 打开 [data/questions.json](data/questions.json)，用 GitHub 的编辑按钮修改，或者在本地编辑。
2. 新增题目时，为它分配唯一的 `id`，例如 `2026-11-21-1`，并指定来源 `source` 和原题号 `number`。如果新增来源，同时更新 `sources`，来源的 `id` 使用发布日期（`YYYY-MM-DD`），并同步对应的 `count`。网页依据来源日期自动显示年份。
3. 保留现有题目 ID。调整题目顺序时保留每道题内部的选项顺序；旧记录按题目 ID 和选项位置保存。更正选项答案时，按需要调整 `answer`。页面会用当前题库重新判定已有作答。
4. 将修改提交到 `main`。仓库的 GitHub Pages 发布源为 `main` 根目录，题库提交后会随原网址更新。用原链接检查题数与一条新增或修改的题目。

选择题的 `answer` 使用从 0 开始的选项位置，例如 `[0, 2]` 表示 A、C。判断题选项仍使用同样规则。填空题在 `fields` 中为每一空列出 `accepted`，第一项作为界面展示的参考答案，其余为可接受写法。每道题都填写 `analysis`。

## 本地检查和离线使用

```sh
node scripts/check-bank.mjs
node scripts/build.mjs
```

第二条命令生成 `dist/index.html`，可直接用浏览器打开。在线网页从 `data/questions.json` 加载题目，本地离线版本则在每次构建时嵌入当时的题库。
